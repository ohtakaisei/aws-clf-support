アプリについて

AWS 認定クラウドプラクティショナー(CLF)試験のための問題集アプリです。1,000 問以上の練習問題、エビングハウスの忘却曲線に基づく復習機能、図解付きの用語集、本番形式の模擬試験で合格を目指せます。

主な機能

  • 試験ガイドの 4 ドメインを網羅した練習問題と丁寧な解説
  • 忘却曲線(1日 → 3日 → 7日 → 14日 → 30日 → 60日)に沿った復習スケジュール
  • 検索・カテゴリフィルター付きの図解用語集
  • 本番形式(65 問・90 分・1000 点満点)の模擬試験
  • 文字サイズ・フォント・出題数などを変えられる柔軟な設定
