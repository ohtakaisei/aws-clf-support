アプリについて

AWS 認定資格の合格を目指すための問題集アプリです。クラウドプラクティショナー(CLF)は無料で全1,050問をご利用いただけます。他の資格は順次追加していきます。

主な機能

  • 試験ガイドの出題分野を網羅した練習問題と、ていねいな解説
  • 忘却曲線(1日 → 3日 → 7日 → 14日 → 30日 → 60日)に沿った復習スケジュール
  • 検索・カテゴリフィルター付きの図解用語集
  • 本番形式の模擬試験(資格ごとの問題数・制限時間・合格ライン)
  • 文字サイズ・フォント・出題数などを変えられる柔軟な設定

料金について

クラウドプラクティショナー(CLF)は完全無料です。その他の資格は、資格ごとの買い切り購入、または全資格が使い放題になる「全資格パス」(月額・年額)からお選びいただけます。有料資格も、購入前に先頭50問を無料でお試しいただけます。

サブスクリプションの解約は、端末の「設定 > Apple ID > サブスクリプション」からいつでも行えます。詳しくは利用規約をご確認ください。

よくあるご質問

Q. 購入した資格が表示されません
アプリ内の「設定 > 購入を復元」をお試しください。購入時と同じ Apple ID でサインインしている必要があります。

Q. 「準備中」の資格はいつ使えますか?
問題・用語集の準備ができ次第、アップデートで順次追加します。全資格パスをご利用中の場合、追加された時点でそのままお使いいただけます。

Q. 問題の内容に誤りを見つけました
お手数ですが下記のメールアドレスまでご連絡ください。確認のうえ、アップデートで修正します。
