本利用規約(以下「本規約」)は、AWS 認定資格対策アプリ(以下「本アプリ」)の利用条件を定めるものです。本アプリをご利用いただくことで、本規約に同意いただいたものとみなします。

1. 本アプリについて

本アプリは、AWS 認定資格(AWS Certification)試験の学習を支援する非公式の学習アプリです。

2. 商標について

Amazon Web Services、AWS、および関連するサービス名・ロゴは、Amazon.com, Inc. またはその関連会社の商標です。本アプリは Amazon Web Services, Inc. およびその関連会社が提供・承認・後援するものではなく、一切の提携関係はありません。

3. 有料コンテンツとアプリ内課金

本アプリの一部の資格コンテンツは有料です。ご利用にあたっては、次のいずれかをお選びいただけます。

  • 単体購入(買い切り): 対象の資格を個別に購入することで、その資格のコンテンツを継続してご利用いただけます。一度購入したものに追加料金は発生しません。
  • 全資格パス(サブスクリプション): 月額または年額の自動更新サブスクリプションです。契約中は、本アプリが対応するすべての資格のコンテンツをご利用いただけます。

価格は、購入前にアプリ内および App Store の購入画面に表示されます。お支払いは、購入確定時にお客様の Apple ID アカウントに請求されます。

4. サブスクリプションの自動更新と解約

  • 全資格パスは、現在の期間終了の 24 時間前までに自動更新をオフにしない限り、自動的に更新されます。
  • 更新料金は、現在の期間終了の 24 時間前以内に Apple ID アカウントへ請求されます。
  • 解約は、お使いの端末の「設定 > Apple ID > サブスクリプション」または App Store のアカウント設定からいつでも行えます。アプリを削除しただけでは解約されません。
  • 解約した場合、契約中の期間が終了するまではコンテンツをご利用いただけます。期間途中の解約による日割りの返金は行われません。
  • 返金については Apple の規定に従います。開発者が個別に返金対応を行うことはできません。

5. 購入の復元

機種変更やアプリの再インストールを行った場合は、同一の Apple ID でサインインのうえ、アプリ内の「設定 > 購入を復元」から購入済みのコンテンツを引き継ぐことができます。

6. 「準備中」の資格について

本アプリには、コンテンツを準備中の資格が表示される場合があります。これらは今後のアップデートでの追加を予定しているものであり、追加の時期・内容を保証するものではありません。全資格パスは、追加された時点で対象資格に含まれます。

7. コンテンツの正確性

収録している問題・解説・用語集は、正確性に十分配慮して作成していますが、その完全性・正確性・最新性を保証するものではありません。AWS のサービス仕様は変更されることがあるため、受験にあたっては必ず AWS 公式の試験ガイド・ドキュメントをあわせてご確認ください。

8. 合格の保証について

本アプリは学習を支援するものであり、試験の合格を保証するものではありません。合否を理由とした返金には応じられません。
